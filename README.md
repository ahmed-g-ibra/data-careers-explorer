# Data Careers Explorer

Interactive single-page guides comparing **Data Analyst**, **Data Engineer** and **Data Scientist**, with learning paths into **DevOps**. Every page has an English / العربية (RTL) switch.

Open `index.html` in a browser and pick a version. No build step or dependencies.

| Version | Path | What's inside |
|---|---|---|
| v1 | [`v1/index.html`](v1/index.html) | Overview, data lifecycle, full comparison table, skills radar, tools, day in the life, same problem solved three ways, career & pay, AI impact & career risk, myths, "which role fits you?" quiz |
| v2 | [`v2/index.html`](v2/index.html) | Everything in v1, plus a **Learning paths** tab: shared foundation skills, a 4-stage path (skills, courses, portfolio project) for each of Data Analyst, Data Engineer, Data Scientist and DevOps with saved progress, a shared-skills matrix with pairwise overlap, the routes into DevOps from each data role, and a **Unified path** tab: one shared core (computing, data & cloud, engineering practices) that covers ~67–75% of every career, then a checkpoint and a specialisation branch, with switch-cost calculator and professional habits |

Ratings, risk levels and timings are the author's estimates, for orientation only. Check course providers for current price and availability.
